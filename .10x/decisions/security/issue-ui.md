# Security — issue-ui

Отчёт: `reviews/2026-11-04-issue-ui-security-review.md`.

- Вход: HS256 с `JWT_SECRET`, только HS256, срок обязателен, refresh не годится как access, refresh
  отзывается сменой пароля; bcrypt; перебор 5/мин на логин и IP; хеш пароля наружу не уходит.
- Права проверяет сервер (403 проверен вживую из браузера участника).
- Токены — в `localStorage` (как planora/kusec): уязвимы к XSS → в интерфейсе нет `v-html`, данные
  событий выводятся только текстом.
- Админский API теперь можно публиковать: без токена — 401 (кроме входа и первого админа, пока людей нет).
