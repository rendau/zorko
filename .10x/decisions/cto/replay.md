# CTO — replay (запись сессий)

Спека: `specs/2026-11-06-replay-design.md` (одобрена пользователем 2026-11-06: «давай начнём реализацию»).

- **Строим, совместимо с `replayIntegration()` SDK Sentry.** Свою библиотеку записи не пишем:
  фронтендеры берут официальный SDK, у seller запись уже включена (`replaysOnErrorSampleRate: 1.0`)
  и заработает без нового билда. Протокол сверен по `@sentry/replay` 11.11.0.
- **Проигрыватель — `@sentry-internal/rrweb-player` (MIT)**, та же ветка rrweb, что пишет SDK.
  Свой проигрыватель не пишем; сервисы Sentry (их интерфейс записи — FSL) не берём.
- **Хранилища — те, что есть:** S3 (сегменты), ClickHouse (описания, связи), Redpanda (отдельная
  тема). Новых сервисов нет.
- **Решения пользователя по умолчанию** (предложены, возражений нет): хранение 30 дней; в примерах
  скрытие всего текста и картинок; тела запросов не пишем. Сайт может решить иначе (seller —
  без скрытия) — zorko принимает то, что прислал сайт.
- **Риск:** объём. Защита — режим `off` по умолчанию, предел в час, остановка записи с сервера.
