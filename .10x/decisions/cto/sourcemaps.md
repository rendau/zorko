# CTO — sourcemaps (шаг 3)

Спека: `specs/2026-11-04-sourcemaps-design.md` (одобрена 2026-11-04).

- **Строим, совместимо с `sentry-cli` / `@sentry/vite-plugin`.** Свой загрузчик карт не пишем:
  фронтендеры берут официальный плагин, меняется адрес и токен. Протокол сверен по исходникам
  `sentry-cli` 3.8.2 (chunk-upload → assemble artifact bundle, org-токен `sntrys_`).
- **Сторонние сервисы символикации (symbolicator Sentry) не берём** — это отдельный Rust-сервис
  с собственной инфраструктурой; против цели «лёгкий zorko». Перевод — внутри Go-обработчика.
- **Библиотеки:** `minio-go` (S3), `go-sourcemap/sourcemap` (карты, с проверкой на картах Vite),
  парсер JS `dop251/goja/parser` (имена функций). Все — чистый Go, без cgo.
- **Риск:** имена функций в сжатом коде — самая хрупкая часть; есть запасные пути (ADR-011).
