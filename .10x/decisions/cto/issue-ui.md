# CTO — issue-ui

**Вердикт:** строим. Без интерфейса шаг 1 не решает боль: ошибки в базе есть, но фронтендеры их не видят.

**Вход переносится из шага 5 в шаг 2** (решение пользователя): иначе интерфейс нельзя отдать людям.
Делаем как в kusec — одинаковый подход во всех своих сервисах, известные свойства и риски.
Общий сервис `jwts` не используем (решение пользователя).

**Фронт** — стек мечтовых админок (Nuxt 4 + Nuxt UI 4), раздача — как в ruto/kusec (предсжатая
статика). Один бандл — требование пользователя (предсказуемая загрузка, без «догрузки» страниц).

**Риски:** Nuxt может сопротивляться сборке в один файл → запасной путь Nuxt UI на Vite + Vue.
