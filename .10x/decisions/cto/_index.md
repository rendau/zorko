# CTO — общие решения

- **Строим своё, а не берём готовое** (решение пользователя, 2026-11-04). Sentry в облаке платный,
  Sentry у себя — около 20 контейнеров и от 16 ГБ памяти. Готовые лёгкие аналоги (GlitchTip,
  Bugsink) рассмотрены и отклонены: нужен свой продукт на своём стеке.
- **Цель:** по функциям и интерфейсу не уступать Sentry в том, что нужно фронтендерам; сотни
  интеграций со сторонними сервисами и ИИ-функции Sentry в цель не входят.
- **Совместимость с SDK Sentry:** клиенты подключают официальные библиотеки Sentry, меняется
  только адрес (DSN). Своих клиентских библиотек не пишем.
- **Стек:** Go (каркас из `rendau/gotemplate`) + Nuxt UI 4 (как админки в `projects/mechta/*`,
  эталон — `planora/admin`). Хранилища: Postgres + ClickHouse + S3.
- **Клиенты:** веб (Vue/React), Flutter, React Native. Нативные iOS/Android — не сейчас.
- **Название:** zorko. Репозиторий — github.com/rendau/zorko (приватный).
