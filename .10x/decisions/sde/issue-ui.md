# SDE — issue-ui: что построено

## Построено (U1–U10)
- **Вход как в kusec:** `domain/session` (HS256, access 15 мин / refresh 30 дней с отпечатком пароля),
  перехватчик gRPC, `domain/usr` + `usecase/usr` (Login, RefreshToken, BootstrapStatus, профиль, CRUD),
  `service/loginlimit` (5 неудач/мин на логин и IP), права в `org`/`project`/`project_key`,
  `not_authorized` → HTTP 401, `no_permission` → 403.
- **Поиск:** `service/searchquery` (`key:value`, `!`, кавычки, `*`, слова, `is:` игнорируется, URL — слово).
- **Чтение ClickHouse:** агрегаты, ряды, топ тегов, ключи/значения, события и соседи.
- **Ручки:** `IssueService` (List/Get/Stat/Tags), `EventService` (List/Get, `latest`/`oldest`),
  `TagService` (Keys/Values).
- **Раздача интерфейса:** `internal/app/admin_http_server.go` — `.br`/`.gz` по `Accept-Encoding`,
  сутки для файлов сборки, `no-cache` для `index.html`, `/config.js`, адреса SPA → `index.html`.
- **Фронт `admin/`:** Nuxt 4 + Nuxt UI 4.12, один JS + один CSS (`check-bundle.mjs`), сжатие
  (`compress.mjs`), ru/en (201 ключ), экраны: вход, первый запуск, проблемы, карточка, проекты, ключи
  с кодом подключения, люди, профиль; незаметное обновление токена.

## Отступления от спеки/плана
1. **Один usecase `issue`** для проблем, событий и тегов вместо трёх: общие проверки (вход, проекты
   организации, период, поиск); три handler-а используют его.
2. **Ручки входа:** пути как в kusec (`/usr/login`, `/usr/token/refresh`, `/usr/bootstrap/status`,
   `/usr/profile`); смена своего пароля требует текущий.
3. **Ошибки входа HTTP-кодами:** перехватчик ошибок и шлюз отдают 401/403 вместо 400 для
   `not_authorized`/`no_permission` — по 401 интерфейс обновляет токен.
4. **Время в запросах ClickHouse — миллисекундами** (`fromUnixTimestamp64Milli`): `time.Time`
   библиотека подставляет с точностью до секунды (найдено тестом соседних событий).
5. **Стенд:** переводы подключены статически в `i18n.config.ts`; отключён `appManifest`
   (опрос `/_nuxt/builds/latest.json`).
6. **Пункт «все окружения»** — служебное значение `__all`: компонент выбора Nuxt UI не принимает пустое.
7. **Таблица `usr`** дописана в `000001_init` (проект не задеплоен — правило «один init до деплоя»).

## Технический долг
- Отключение человека действует до 15 минут (access без БД — решение пользователя, ADR-005).
- Список проблем: все проблемы периода агрегируются на каждый запрос (ADR-006); предел 50 000.
- Подсказки тегов за 30 дней по всей организации — `array join` по `event_stat`; на больших объёмах
  может понадобиться материализованное представление ключей.
- Level C (скрипт вёрстки) не умеет входить — автоматически проверена только страница входа.
