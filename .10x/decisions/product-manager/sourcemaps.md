# Product Manager — sourcemaps (шаг 3)

**Кому:** фронтендерам — стек ошибки в исходных файлах и именах, одна проблема на одну ошибку
независимо от релиза.

## Решения пользователя (2026-11-04)
- Перевод стека — при приёме ошибки.
- Карта удаляется после 30 дней без ошибок по ней.
- CI входит токеном организации (`sntrys_…`), админ создаёт, показывается один раз.
- Поиск карты по метке и по релизу с путём (старые SDK).
- Если из CI карты нет — скачать с сайта; выключено по умолчанию, настраиваемо, без постоянных
  запросов (команда не публикует `.map`).

## Истории
- Фронтендер добавляет `@sentry/vite-plugin` с токеном zorko → сборка проходит, карты залиты.
- Открывает проблему → видит `src/pages/Cart.vue:87` в `applyPromo` и код вокруг.
- Выпускает релиз → та же ошибка остаётся той же проблемой.
- Админ создаёт/удаляет токены CI; видит залитые карты и удаляет лишние.
- Проект без CI: админ включает «карты с сайта» для `admin.mdev.kz` → стек переводится.
- Карта не применилась → в карточке видно почему.

## Успех
Критерии готовности спеки (раздел «Критерии готовности»).

## Не входит
RN/Flutter (шаг 6), файлы отладки, `sentry-cli` 1.x, повторный перевод принятых ошибок,
коммиты и деплои (шаг 4), поиск по функции, перенос старых проблем.
