# Product Manager — общие решения

**Боль:** фронтендеры не видят ошибок и логов с устройств клиентов.

## Дорожная карта (согласована с пользователем 2026-11-04)
1. **error-ingest** — приём событий в формате Sentry, очередь, группировка в проблемы, хранение.
2. Интерфейс: список проблем с поиском и фильтрами, карточка проблемы.
3. Карты исходников (совместимо с `@sentry/vite-plugin` / `sentry-cli`).
4. Релизы, статусы (решено / отложено / вернулось), оповещения в Telegram.
5. Команды, доступ к отдельным проектам, TOTP, API-ключи. (Вход с ролями админ/участник перенесён в шаг 2 — решение пользователя 2026-11-04.)
6. Flutter и React Native: их стеки и карты.

Дальше (этапы 2–5 из обсуждения): логи с устройств, скорость (трассировки, Web Vitals),
запись сессий (взята в работу 2026-11-06, до шага 4 — `replay`), отзывы пользователей, проверка доступности, cron-мониторы, дашборды.
