# Product Manager — replay

**Кому:** фронтендерам — увидеть, что человек делал до ошибки, без воспроизведения наугад.

## Решения пользователя (2026-11-06)
- Запись при ошибке и по выбору — часть всех сессий; режим в проекте, по умолчанию выключено.
- Сначала сайты; мобильные (видео) — позже.
- Хранение 30 дней, скрытие всего в примерах, без тел запросов — по умолчанию.

## Истории
- Админ включает в проекте режим «при ошибке» → у новых ошибок в карточке есть запись.
- Фронтендер открывает проблему → «Записи» → проигрыватель с минутой до ошибки, консолью,
  запросами, отметкой ошибки.
- Админ выбирает «часть сессий» → в примере подключения доля; после релиза сайта в «Записях»
  появляются сессии без ошибок.
- Записей слишком много → админ ставит «выключено» или меньший предел → браузеры перестают слать
  сразу, без релиза сайта.
- Запись не пришла → в карточке видно возможные причины.

## Успех
Критерии готовности спеки.

## Не входит
Мобильные записи, canvas, тела запросов, отзывы, удаление вручную, поиск внутри записи.
