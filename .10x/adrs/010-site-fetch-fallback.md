# ADR-010: Карты с сайта — запасной путь, выключен по умолчанию, со списком хостов и памятью

**Status:** Accepted
**Date:** 2026-11-04
**Feature:** sourcemaps
**Author:** 10x-Team (Architect + Security)

## Context
Не у всех проектов есть CI. Пользователь: «если из CI не получилось — с сайта; настраиваемо,
чтобы постоянно не долбить (команда не планирует публиковать map)». Адрес файла приходит в ошибке,
которую может прислать кто угодно → риск SSRF (заставить zorko ходить во внутреннюю сеть).

## Decision
- Только после неудачи поиска из CI; только если в проекте включено; только `http(s)` и хост из
  списка проекта (пустой = никуда). Адрес после DNS проверяется в `Dialer.Control`: запрещены
  loopback, link-local (в т.ч. `169.254.169.254`), unspecified; частные сети разрешены (внутренние
  админки), защиту даёт список хостов. Перенаправления ≤ 3, каждое — та же проверка.
- Память результата: `site_fetch(project_id, url)` — удача и неудача; повтор не раньше интервала
  проекта (60 мин по умолчанию). Скачанное складывается архивом `source=site` в те же таблицы и S3.
- Один запрос на адрес внутри копии (singleflight); 4 одновременно; 5 с; до 50 МБ.
- Необязательный секретный заголовок проекта; значение наружу не отдаётся.

## Alternatives Considered
| Alternative | Pros | Cons | Why Not |
|---|---|---|---|
| Не качать с сайта | нет SSRF | проекты без CI без карт | просьба пользователя |
| Качать всегда, как Sentry по умолчанию | без настройки | долбит сайты, где карт нет | пользователь против |
| Качать при показе карточки | не тормозит приём | склейка по сжатым именам | противоречит ADR-008 |
| Запрещать и частные сети | строже | внутренние админки не работают | список хостов уже ограничивает |

## Consequences
### Positive
- Проекты без CI получают перевод одной галочкой.
### Negative
- `app.js` без хеша может смениться за интервал → старая карта до следующей проверки.
- Значение секретного заголовка хранится в PG открыто (нужно для отправки).
### Risks
- SSRF через DNS-подмену разрешённого хоста — проверка адреса при соединении, а не по имени.

## Dependencies
ADR-008, ADR-009 (хранение скачанного).
