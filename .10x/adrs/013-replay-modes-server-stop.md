# ADR-013: Режимы записи в проекте и остановка записи с сервера через X-Sentry-Rate-Limits

**Status:** Accepted
**Date:** 2026-11-06
**Feature:** replay
**Author:** 10x-Team (Architect + Staff Engineer)

## Context
Записывать или нет, решает SDK в браузере (`replaysOnErrorSampleRate`, `replaysSessionSampleRate`).
Пользователь хочет включать и выключать запись в zorko, без релиза сайта. SDK 11.11 останавливает
запись сессии при ответе не 2xx или при заголовке `X-Sentry-Rate-Limits` с категорией `replay`;
ошибки при этом продолжают уходить.

## Decision
- В проекте: `replay_mode` (`off` | `error` | `session`), `replay_session_rate` (только для примера
  подключения), `replay_hour_limit`. Настройки доходят до приёма через кэш проектов
  (`service/projectlabel`, перечитка 30 с).
- Отброшенная запись (режим, тип, предел, нет S3): ответ 200 (события конверта обрабатываются)
  + `X-Sentry-Rate-Limits: <сек>:replay:project`. 3600 с для режима; до конца часа — для предела.
  Если в том же ответе уже есть предел событий (429), он важнее.
- `error` отбрасывает `replay_type = session`; предел считает новые записи (`segment_id = 0`) в
  памяти копии по часам.

## Alternatives Considered
| Alternative | Pros | Cons | Why Not |
|---|---|---|---|
| Только настройки SDK | ничего на сервере | выключить — только релизом сайта | против решения пользователя |
| Удалённые настройки (сайт спрашивает zorko при загрузке) | долю можно менять из zorko | свой код в примере, лишний запрос на каждой странице, хрупко при смене SDK | YAGNI; выключение и так мгновенное |
| Тихо отбрасывать без заголовка | проще | браузер пишет и шлёт до конца сессии — трафик посетителя впустую | заголовок бесплатен |
| Ответ 429 на запись | понятно SDK | 429 относится ко всему конверту, ошибки в нём пропадут | 200 + заголовок точнее |

## Consequences
### Positive
- Выключение и предел действуют за ≤30 с во всех браузерах, без релиза.
### Negative
- Долю сессий zorko не поднимет: она в коде сайта.
- Предел приблизительный при нескольких копиях приёма (до N × предела).
### Risks
- Будущий SDK изменит реакцию на заголовок → проверка вживую в R10, тест на формат заголовка.

## Dependencies
Кэш проектов, предел ключа (ratelimit) — по аналогии.
