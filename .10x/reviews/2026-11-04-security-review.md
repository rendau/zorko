# Security-обзор: error-ingest — 2026-11-04

## Публичный приём
| Угроза | Защита | Статус |
|---|---|---|
| Спам по публичному ключу | лимит ключа (429 + `Retry-After`), `allowed_origin` | ✅ проверено |
| Перебор ключей нагружает БД | ключи в памяти, промах — 403 без запроса в PG | ✅ |
| Сжатая бомба | предел до и после распаковки, обрыв на пределе | ✅ 200 МБ → 413 за 15 мс |
| Огромное событие / глубокий JSON | предел события 1 МБ; глубина — предел `encoding/json` (10 000) | ✅ |
| Много параллельных больших тел | — | ⚠️ нет общего предела памяти (долг) |
| Чужой сайт с подменой Origin вне браузера | Origin — защита от чужих сайтов в браузерах, не от скриптов | ℹ️ ограничение протокола Sentry |

## Данные пользователей
- Вычистка ключей `password, passwd, secret, token, api_key, apikey, auth, cookie, session, csrf,
  card, cvv` во всём событии, включая заголовки списком пар и хлебные крошки; номера карт по Луну.
- IP — только при `{{auto}}` (`sendDefaultPii`).
- ⚠️ Строки исходного кода, которые SDK прикладывает к стеку, не чистятся (как в Sentry).
