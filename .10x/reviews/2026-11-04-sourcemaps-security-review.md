# Security — sourcemaps (шаг 3), 2026-11-04

## Модель угроз и меры
| Угроза | Мера | Итог |
|---|---|---|
| Утечка токена CI | в PG только SHA-256; показ один раз; в логах — последние 4 символа; права — только заливка и релизы своей организации; удаление действует сразу (проверка по базе) | ok |
| Токен одной организации в другую | организация пути сверяется с токеном → 403; проекты ищутся только внутри организации | ok, проверено |
| Токен CI к ручкам интерфейса | шлюз ждёт JWT → 401 | ok, проверено |
| SSRF через адрес файла в ошибке | выключено по умолчанию; только `http(s)` и хост из списка проекта (пусто = никуда); адрес проверяется после DNS при соединении (loopback, link-local вкл. `169.254.169.254`, unspecified, multicast; IPv4-mapped разворачивается); ≤3 перенаправления, каждое — хост из списка; прокси не используется | ok, тесты |
| Секретный заголовок сайта | не отдаётся ручками (только «задан»); уходит лишь на хосты из списка (перенаправление на другой — отказ) | ok; лежит в PG открытым текстом (нужен для отправки) |
| Архив-бомба, мусор | кусок ≤ 8 МБ распакованным, запрос ≤ 32 МБ, архив ≤ 1 ГБ, файл ≤ 200 МБ, всего ≤ 2 ГБ, ≤ 20 000 файлов; SHA-1 каждого куска и всего архива | ok, тесты |
| Пути в архиве (zip slip) | файлы не пишутся на диск по именам: zip читается из одного временного файла, в S3 — под SHA-1 | n/a |
| Нагрузка заливкой | ≤ 2 сборки на копию, остальные ждут; тело ограничено | приемлемо; нет предела на число заливок с токена (CI доверенный) |
| Права в интерфейсе | токены — только админ; удалить архив, менять сайт — админ; смотреть карты и историю сайта — все | ok, проверено (403) |
| Исходный код в zorko | карты несут исходники; в карточке видны строки кода; бакет S3 должен быть закрытым | принято |
| Телеметрия плагина в sentry.io | в примере `telemetry: false` | ok |
| Общие куски/файлы между организациями | хранятся по SHA-1 содержимого; доступ к файлу — только через архив своей организации и проекта | ok |

## Остаточные риски
- Значение секретного заголовка в PG открыто.
- Нет ограничения частоты заливок с одного токена.
- Удалённый архив до минуты может применяться обработчиком.

Серьёзных открытых замечаний нет.
