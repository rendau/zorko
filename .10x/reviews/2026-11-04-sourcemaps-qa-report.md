## Найдено и исправлено
1. goja не разбирает ES-модули → `demodule` (до кода).
2. Плагин 11 ходит в `GET /api/0/organizations/{org}/` → ручка добавлена.
3. Ошибки `ErrFull` в Sentry API отдавались как 503 → разбор кода из `ErrFull`.
4. Порядок `assemble`: повторный запрос после дозаливки получал бы «ошибку» → сначала состояние, потом
   куски, потом замок.
5. Причина для внутреннего адреса сайта вводила в заблуждение → `site_address_blocked`.
6. Подсказка поля «Значение заголовка» не помещалась, подпись «Выключено…» при включённом переключателе,
   прокрутка к `#maps` до загрузки страницы.
