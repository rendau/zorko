# Security — replay (запись сессий), 2026-11-06

## Модель угроз и меры
| Угроза | Мера | Итог |
|---|---|---|
| Чужие записи по номеру | номер записи придумывает браузер — везде пара `(project_id, replay_id)`; список, запись, тело сегмента, записи проблемы проверяют доступ к проекту (`access.CheckProject` / `ProjectAccess`) | ok, тесты |
| Тело сегмента без входа | ручка на шлюзе разбирает JWT так же, как gRPC; без входа 401, чужой проект 403, кэш `private` | ok, тесты |
| Подделанная запись выполняет код у зрителя | rrweb не переносит `<script>`, рамка `sandbox` без `allow-scripts` (проверено в Chrome) | ok |
| Подделанная запись грузит ресурсы с чужих адресов (засвет IP зрителя) | принято в спеке; в примере `blockAllMedia` | принято |
| Мусор через публичный DSN | проверка сайта ключа, тело ≤ 10 МБ, описание ≤ 1 МБ, номер сегмента ≤ 1000, длина ≤ 61 мин, предел новых записей в час | ok |
| Переполнение S3 | режим `off` по умолчанию, предел в час, стоп в браузере, уборка 30 дней | ok |
| Личные данные в записи | пример скрывает текст и картинки; сайт может выключить (seller) — предупреждение в настройках и README; консоль SDK пишет как есть; описание проходит ту же вычистку, что события (`normalize`) | принято |
| Связь с чужой проблемой подделанным тегом | связь пишется в проект события; в отметках показываются только проблемы того же проекта | ok, тест |
| Режим записи меняет участник | `PUT /project` — только админ; без S3 режим не включить | ok |

## Открытые замечания
- Нет серьёзных. Предел в час приблизительный при нескольких копиях приёма (техдолг, не уязвимость).
